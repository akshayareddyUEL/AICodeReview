# Project overview

This AI Code Review tool is a Flask web application that analyzes Python code using LLM technology. Users can either paste code directly or upload .py files for comprehensive analysis. The system performs three key functions: error detection to identify bugs and syntax issues, generation of improvement comments for code optimization, and an overall quality assessment with a 1-10 rating. The interactive dashboard displays results in separate panels with visual feedback, including a dynamic gauge chart for ratings. The tool provides actionable insights to help developers improve code quality, maintainability, and adherence to best practices through AI-powered review.


Developed Module - CN701 - Advanced Software Engineering
Institution - University of East London

# Project Main Use Cases

1. Code Input Flexibility: Accepts Python code through both direct text pasting and file upload (.py format) for user convenience.

2. AI-Powered Analysis: Utilizes LLM (GPT) to intelligently review code for errors, suggest improvements, and assess overall quality.

3. Three-Part Review System: Provides comprehensive feedback through dedicated panels for Error Detection, Comments/Suggestions, and Overall Review.

4. Visual Rating Scale: Generates a 1-10 quality score with animated gauge/pie chart visualization and color-coded quality classification.

5. Actionable Insights: Delivers specific, actionable feedback including bug identification, optimization suggestions, and maintainability improvements.
